Privacidad

Privacidad, sin letra chica innecesaria.

Esta política describe el funcionamiento del sitio público de Data Guasu.

Datos que recopila este sitio

Este sitio informativo no incluye formularios, cuentas de usuario ni herramientas propias de seguimiento. Data Guasu no recopila datos personales directamente a través de estas páginas.

Enlaces externos

El sitio enlaza a LinkedIn y puede incorporar en el futuro un correo profesional o una herramienta de agenda. Al seguir un enlace externo, se aplican las políticas de privacidad de ese proveedor.

Hosting y registros técnicos

El proveedor de hosting puede procesar información técnica básica —como dirección IP, tipo de navegador y registros de seguridad— para entregar y proteger el sitio. Ese tratamiento depende de la infraestructura de GitHub Pages.

Cambios

Si se incorporan analytics, formularios u otras herramientas que procesen datos, esta política se actualizará antes de publicarlas.

Contacto

Las consultas sobre privacidad pueden dirigirse a Nicolás Escobar mediante el perfil profesional enlazado en este sitio.
