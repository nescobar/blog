# Legacy URL map

The previous site mixed custom-domain URLs with `/blog/` paths generated by an incorrect Jekyll `baseurl`. Astro now builds for the custom-domain root without a repository-name prefix.

| Legacy URL                                                                        | Destination                  | Rationale                                             |
| --------------------------------------------------------------------------------- | ---------------------------- | ----------------------------------------------------- |
| `/about/`                                                                         | `/nosotros/`                 | Founder and practice profile                          |
| `/search/`                                                                        | `/archivo/`                  | Search is replaced by the complete archive index      |
| `/categories/`                                                                    | `/archivo/`                  | Categories are replaced by the complete archive index |
| `/visualize-databricks-dashboard-tableau/`                                        | Preserved                    | Canonical English article at its original public URL  |
| `/Building-a-notebook-based-ETL-framework-with-Spark-and-Delta-Lake/`             | Preserved                    | Canonical English article at its original public URL  |
| `/Utilizando-Twitter-para-Monitorear-los-Reclamos-de-la-Ciudadanía-(2)/`          | Preserved                    | Canonical Spanish article at its original public URL  |
| `/Analisis-Twitter-MuniAsu/`                                                      | Preserved                    | Canonical Spanish article at its original public URL  |
| `/Tennis-Analytics/`                                                              | Preserved                    | Canonical English article at its original public URL  |
| `/Data-Guasu/`                                                                    | Preserved                    | Canonical English article at its original public URL  |
| `/blog/`                                                                          | `/`                          | Old Jekyll base path                                  |
| `/blog/about/`                                                                    | `/nosotros/`                 | Old Jekyll base path                                  |
| `/blog/search/`                                                                   | `/archivo/`                  | Old Jekyll base path                                  |
| `/blog/categories/`                                                               | `/archivo/`                  | Old Jekyll base path                                  |
| `/blog/<original-article-slug>/`                                                  | Canonical article            | Removes the erroneous repository base path            |
| `/feed.xml` and `/blog/feed.xml`                                                  | Archive feed                 | Preserves existing feed subscribers                   |
| `/blog/twitter/nlp/eda/2019/11/18/analisis_tweets_municipalidad.html`             | `/Analisis-Twitter-MuniAsu/` | Generated notebook route                              |
| `/blog/tennis/eda/2018/10/12/data-visualizations-of-atp-tennis-competitions.html` | `/Tennis-Analytics/`         | Generated notebook route                              |

GitHub Pages does not support server-side status-code redirects. The mapped routes build as lightweight `noindex` HTML pages with an immediate refresh, a canonical destination, and a usable fallback link. If the site later moves behind a redirect-capable host, replace these with HTTP 301 redirects.
